# Medicare Hospital Appointment System 🏥

A complete console-based hospital management and appointment scheduling system developed entirely in **C Language**. This academic project demonstrates strong foundational programming skills and logic building.

## 🚀 Features
* **Patient Registration:** Auto-generates unique Patient IDs (MR Numbers).
* **Smart Symptom Checker:** Automatically recommends doctors based on selected patient symptoms.
* **Billing & Discounts:** Calculates fees based on the doctor and automatically applies a 20% discount for senior citizens (60+ years).
* **File Handling:** Saves all patient records and invoices persistently in a `.txt` file using C File I/O operations.

## 💻 Tech Stack
* **Language:** C
* **Core Concepts:** Procedural Programming, Control Structures, Switch-Cases, File Handling.
